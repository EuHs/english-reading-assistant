📖 英语阅读助手

快速上手

  1. 网页或 PDF 中选中文本 → 弹出工具条：译 / 🔊 / 高亮 / 下划线 / 批注 / ＋生词 / ★好句 / 语法。
  2. 右键选中文本 → “英语阅读助手” 菜单：加入生词本、加入好词好句、语法分析等。
  3. 打开 .pdf 链接会自动进入学习阅读器（可在设置中关闭）；也可在弹窗中打开本地 PDF。
  4. AI：在“设置 → AI 接口”填入 OpenAI 兼容接口，或配置本机跳板（one-api/new-api/LiteLLM），或直接使用服务器端 AI。
  5. 服务器：填写服务器地址与 API Token 并启用，生词和好词好句会自动同步，可在网页端测验与统计。
